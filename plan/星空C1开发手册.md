# 星空C1 (StarrySkyC1) 开发手册

> 基于 [embedded-sdk](https://github.com/openecos-projects/embedded-sdk) 和 [星空C1文档](https://embedded.openecos.com/zh-cn/latest/page/brd/starry-sky-c/v1.0/) 整理

---

## 一、板卡概述

星空C1 主控芯片采用自研 **retroSoC**，内部集成开源 RISC-V 处理器核 **PicoRV32**。

### 芯片规格

| 项目 | 参数 |
|------|------|
| 处理器核心 | PicoRV32 |
| 指令集 | RV32IMAC |
| 工作频率 | 72MHz |
| 片上 SRAM | 128KB (`0x00000000 - 0x0001FFFF`) |
| 外部 PSRAM | 8MB (`0x04000000 - 0x047FFFFF`) |
| SPI Flash | 16MB (`0x30000000 - 0x30FFFFFF`) |

### 板卡外设接口

- 1个电源开关 + 红色电源指示灯
- 1个 TypeC 接口（USB供电 + UART调试，使用 CP2102 协议转换）
- 1个 HFP-LINK 拖拽式烧录器
- 1个 24M 有源晶振
- 1个 4位 CLK 配置拨码开关
- 1个复位按键
- 1个 PS2 接口
- 1个 8MB PSRAM
- 1个 128Mbit SPI Flash
- 5组 IO 引脚扇出

### SoC 外设模块

| 类型 | 外设 |
|------|------|
| 通信接口 | UART (115200 8N1)、HP UART、SPI、HK SPI、I2C、PS2 |
| 存储控制 | Flash、PSRAM |
| GPIO | 16路通用输入输出 |
| PWM | 4路脉宽调制输出 |
| Timer | 2路定时器 (TIM0, TIM1) |
| 其他 | RNG随机数生成器、ArchInfo |

> **注意**：该板卡功能/性能与 ST F1 中低端系列相当，但因可能存在的软硬件错误，仅作为嵌入式原型搭建使用（测试/比赛等），**不要应用到实际生产环境**。

## 二、开发环境安装

### 环境依赖

- RISC-V 交叉编译工具链 (`riscv64-unknown-elf-gcc` / `riscv32-unknown-elf-gcc`)
- `make`
- `direnv`（推荐，用于 testdir 自动加载环境变量）
- Python 3（可选）
- `gcc`, `wget`, `unzip`, `git`（安装脚本依赖）

### 一键安装

```bash
git clone https://github.com/openecos-projects/embedded-sdk.git
cd embedded-sdk
./install.sh
```

安装后需要重载环境变量：

```bash
# bash 用户
source ~/.bashrc
# zsh 用户
source ~/.zshrc
```

### 验证安装

```bash
# 检查 ecos 工具
ecos help
# 检查工具链
riscv64-unknown-elf-gcc --version
```

### 环境变量（安装脚本自动配置）

| 变量 | 值 |
|------|-----|
| `PATH` | `$HOME/.local/ecos-sdk/bin` |
| `PATH` | `$HOME/.local/ecos-sdk/toolchain/riscv_unknown/bin` |
| `ECOS_SDK_HOME` | `$HOME/.local/ecos-sdk` |

## 三、标准开发流程

### 1. 创建独立工程

> **警告**：绝对禁止在 SDK 的 `templates/` 目录内直接修改和编译！必须在 SDK 外部创建独立工程。

```bash
cd ~/my_workspace/
# 格式: ecos init_project <模板名> -name <工程名> -target <板卡型号>
ecos init_project smoke_test -name my_smoke_test -target c1
cd my_smoke_test
```

板卡 target 参数：`c1` / `c2` / `l3` / `l3_1`

### 2. 配置系统（Kconfig）

**交互式图形配置（推荐日常使用）**：

```bash
make menuconfig
```

**无头默认配置（CI/AI Agent 自动化）**：

```bash
$ECOS_SDK_HOME/tools/kconfig/build/conf --alldefconfig Kconfig
$ECOS_SDK_HOME/tools/kconfig/build/conf --syncconfig Kconfig
```

#### menuconfig 分类说明

| 分类 | 说明 |
|------|------|
| System Read-Only Information | 板卡型号相关只读信息 |
| System Configuration | 板卡型号相关可配置信息 |
| Peripheral Drivers | 外设驱动相关配置 |
| External Devices | 外部设备驱动配置 |
| Build Configuration | 编译链接相关配置（含 TimmoLog 等库选项） |
| Firmware Configuration | 固件最终构建配置 |

### 3. 编译固件

```bash
make -j$(nproc)
```

编译产物（在 `build/` 目录下）：

| 文件 | 用途 |
|------|------|
| `retrosoc_fw.elf` | ELF 调试文件 |
| `retrosoc_fw.hex` | 十六进制文件 |
| `retrosoc_fw.bin` | 二进制烧录文件 |

编译完成后会输出 Flash/MEM 内存占用报告。

### 4. 烧录

1. USB 数据线连接板卡与 PC
2. **FLASH_SEL 开关选择 MCU**
3. 打开板卡电源
4. 将 `.bin` 文件拖拽至 HFP-LINK 窗口
5. 等待 LED4 停止闪烁，确认状态显示 Success

### 5. 启动运行

1. 断电，将 **FLASH_SEL 开关选择 CHIP**
2. 打开电源，确认红色电源指示灯亮起
3. 打开串口终端（如 Tabby），配置：
   - 波特率：115200
   - 数据位：8
   - 校验位：无
   - 停止位：1
4. 按下复位按键，检查串口输出

### 上电测试（出厂固件）

- **模式选择**：开关选择 CHIP
- **拨码开关**：从左至右为 `0100`
- 连接 TypeC，打开电源，串口 115200 检查输出

## 四、HAL V2 API 迁移指南

SDK 已全面废弃旧版直接寄存器操作。编写新代码或迁移老工程时：

| 功能 | 旧版 API | HAL V2 API |
|------|----------|------------|
| 串口初始化 | `sys_uart_init()` | `hal_sys_uart_init()` |
| I2C总线 | `i2c_init(...)` | `hal_i2c_init(...)` |
| 定时延时 | `delay_s()` / `delay_ms()` | `hal_delay_ms(timer_id, ms)` |
| 系统滴答 | `sys_tick_init()` | `hal_sys_tick_init(0)` + `hal_get_sys_tick(0)` |
| GPIO配置 | 位掩码拼接 `PADDIR`/`PADOUT` | `gpio_hal_set_mux(port, pin, func)` + `gpio_hal_set_fcfg(port, pin, mode)` |

### 常用 HAL 接口

```c
// 系统串口
void hal_sys_uart_init(void);
void hal_sys_putchar(char c);
void hal_sys_putstr(char *str);

// GPIO
void gpio_hal_input_enable(uint8_t gpio_id, uint8_t gpio_num);
void gpio_hal_output_enable(uint8_t gpio_id, uint8_t gpio_num);
void gpio_hal_set_level(uint8_t gpio_id, uint8_t gpio_num, uint8_t level);
uint8_t gpio_hal_get_level(uint8_t gpio_id, uint8_t gpio_num);
```

## 五、TimmoLog 日志系统

### 启用

在 `make menuconfig` 中：`Build Configuration -> Library Configuration -> TimmoLog Support`

### 使用示例

```c
#include "log.h"

int main() {
    hal_sys_uart_init();
    log_init(LOG_DEBUG, NULL);

    log_info("[SYSTEM] 设备启动成功");
    log_warn("检测到异常输入，自动跳过...");
    log_error("硬件初始化失败！");

    return 0;
}
```

## 九、分离式工程（Isolated Project）

适用于需要脱离 SDK 环境编译的场景：

```bash
ecos init_project <项目名称> -isolated -name <新名称> -target <板卡>
make menuconfig
make
```

> 注意：目前仅适配 C2 板卡；脱离 SDK 后如需 menuconfig 需重新接入 SDK 环境。

## 十、注意事项总结

1. **禁止在 SDK 的 `templates/` 目录内编译**，必须创建独立工程
2. 安装后必须 `source ~/.bashrc` 或重开终端
3. 烧录时 FLASH_SEL 选 **MCU**，运行时选 **CHIP**
4. 拨码开关默认从左至右 `0100`
5. 串口参数固定：115200 8N1
6. 编译命令 `make -j$(nproc)`，产物在 `build/` 目录
7. 新代码必须使用 HAL V2 API，禁止直接操作寄存器
8. 该板卡仅用于原型验证，勿用于生产环境
