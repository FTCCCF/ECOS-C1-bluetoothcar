## 项目上下文（每个阶段都要加载）

### 项目信息
- **项目**：2驱蓝牙遥控小车
- **开发板**：星空C1（retroSoC），RISC-V RV32IMC，72MHz
- **SDK**：ECOS-SDK，WSL 路径 `~/embedded/embedded-sdk`
- **项目目录**：WSL `~/rc_car/`
- **编译工具链**：`riscv64-unknown-elf-gcc`（WSL 已安装）
- **烧录方式**：HFP-LINK 拖拽烧录（你把 .bin 拖入开发板虚拟U盘）
- **调试串口**：SYS_UART，115200 8N1，Windows Tabby 连接 COM5
- **编译命令**：`cd ~/rc_car && make`

### 硬件配置
- **电机驱动**：TB6612FNG 模块，驱动2个TT直流减速电机
- **蓝牙模块**：HC-05（带底板），SPP经典蓝牙，UART透传
- **电源**：7.4V 2S锂电池 → LM2596降压到5V

### 引脚分配表

| 功能 | 开发板引脚 | 连接目标 | 方向 |
|------|-----------|---------|------|
| 蓝牙接收 | CUST_UART_RX | HC-05 TX | 输入 |
| 蓝牙发送 | CUST_UART_TX | HC-05 RX | 输出 |
| 左电机方向1 | GPIO_0 | TB6612 AIN1 | 输出 |
| 左电机方向2 | GPIO_1 | TB6612 AIN2 | 输出 |
| 右电机方向1 | GPIO_2 | TB6612 BIN1 | 输出 |
| 右电机方向2 | GPIO_3 | TB6612 BIN2 | 输出 |
| 左电机调速 | PWM_CH0 | TB6612 PWMA | 输出 |
| 右电机调速 | PWM_CH1 | TB6612 PWMB | 输出 |
| TB6612使能 | 3.3V | TB6612 STBY | 电源 |

### 指令协议

| 指令 | 功能 | 执行动作 |
|------|------|---------|
| F | 前进 | 双电机正转，PWM=当前速度 |
| B | 后退 | 双电机反转，PWM=当前速度 |
| L | 左转 | 左电机反转，右电机正转 |
| R | 右转 | 左电机正转，右电机反转 |
| S | 停车 | 双电机停止（PWM=0） |
| 1~5 | 调速 | 设置PWM占空比 20%/40%/60%/80%/100% |
| H | 心跳 | 回复确认，重置超时计时器 |

### 关键约束
- PWM频率：10kHz
- UART波特率：115200 8N1
- 心跳超时：1000ms无指令自动停车
- 默认速度档位：3（60%占空比）
- retroSoC有16路GPIO、4路PWM、标准UART和HP_UART

## Phase 1：GPIO驱动开发

### 目标
使用ECOS-SDK的GPIO API，配置4路GPIO为输出模式，控制TB6612的4个方向引脚（AIN1/AIN2/BIN1/BIN2），实现电机的正转、反转、停止控制（不含调速）。

### 上下文
- TB6612方向控制真值表：

| AIN1 | AIN2 | 电机A状态 |
|------|------|----------|
| 0 | 0 | 停止（制动） |
| 0 | 1 | 反转 |
| 1 | 0 | 正转 |
| 1 | 1 | 停止（制动） |

- C1 GPIO寄存器（来自 board.h）：
  - `REG_GPIO_0_DR` (0x03000000) — 数据寄存器
  - `REG_GPIO_0_DDR` (0x03000004) — 方向寄存器（1=输出）
- 引脚对应：GPIO_0→AIN1, GPIO_1→AIN2, GPIO_2→BIN1, GPIO_3→BIN2

### 验收标准
- [ ] 4路GPIO能按真值表输出正确电平
- [ ] 串口调试日志正常打印
- [ ] 接上电机+TB6612后（PWMA/PWMB接3.3V拉满），电机能正转、反转、停止

## Phase 2：PWM驱动开发

### 目标
配置2路PWM输出（10kHz），通过占空比控制电机转速。

### 上下文
- C1 PWM寄存器（来自 board.h）：
  - `REG_PWM_0_CTRL` (0x03004000) — 控制寄存器
  - `REG_PWM_0_PSCR` (0x03004004) — 预分频
  - `REG_PWM_0_CMP` (0x0300400c) — 比较寄存器
  - `REG_PWM_0_CR0` (0x03004010) — 通道0（左电机PWMA）
  - `REG_PWM_0_CR1` (0x03004014) — 通道1（右电机PWMB）
- 频率：10kHz，占空比 0~100%
- 速度档位：1=20%, 2=40%, 3=60%, 4=80%, 5=100%，默认3

### 验收标准
- [ ] 2路PWM能输出10kHz波形
- [ ] 5档速度可调，电机转速明显不同
- [ ] PWM=0时电机完全停止

## Phase 3：UART驱动与蓝牙通信

### 目标
配置CUST_UART（即HP_UART），115200 8N1，实现与HC-05蓝牙模块的数据收发。

### 上下文
- C1 HP_UART寄存器（来自 board.h）：
  - `REG_UART_1_LCR` (0x03003000) — 线路控制
  - `REG_UART_1_DIV` (0x03003004) — 分频
  - `REG_UART_1_TRX` (0x03003008) — 收发
  - `REG_UART_1_FCR` (0x0300300c) — FIFO控制
  - `REG_UART_1_LSR` (0x03003010) — 线路状态
- 波特率：115200 8N1
- HC-05 默认波特率可能是9600，需AT指令改为115200
- SYS_UART 走调试日志，CUST_UART 走蓝牙，独立工作

### 验收标准
- [ ] 手机能搜索到HC-05并配对
- [ ] 手机发送字符，串口能收到并打印
- [ ] 双向通信稳定无乱码

## 执行节奏

| 阶段 | 我的工作 | 你需要做的 |
|------|---------|-----------|
| Phase 0 | ✅ 已完成 | 已调通串口 |
| Phase 1 | 写GPIO驱动代码+编译 | 烧录.bin + 复位 + 观察现象反馈 |
| Phase 2 | 写PWM驱动代码+编译 | 同上 |
| Phase 3 | 写UART+蓝牙代码+编译 | 同上 |
| Phase 4 | 整合代码+编译 | 同上 |
| Phase 5 | 分析排查问题 | 搭硬件 + 告诉我现象 |
| Phase 6 | 优化代码 | 验收 |

### 关键原则
1. **逐阶段验证**，过了再进下一阶段
2. **先信号后动力** — 先测GPIO电平，再上电机
3. **先低速后高速** — 首次测试用1档
4. **每次只改一个变量** — 出问题时一次只排查一个可能原因
5. **日志先行** — 看不到串口输出不继续

### 调试提示词（每次测试前请执行）

烧录完成后，按以下步骤检查输出：

1. 打开串口终端（如 Tabby / Putty）
2. 配置串口参数：
   - 波特率：**115200**
   - 数据位：**8**
   - 校验位：**无**
   - 停止位：**1**
3. 开发板 **FLASH_SEL 拨到 CHIP**
4. 按下 **复位键**
5. 检查终端是否能正常输出日志信息
6. 将看到的输出内容和硬件现象反馈给我
