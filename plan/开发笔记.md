# 星空C1 (retroSoC) 开发笔记

> 本项目：四轮蓝牙遥控小车
> 开发板：星空C1 (retroSoC)，RISC-V RV32IMC，72MHz
> SDK：ECOS-SDK，路径 WSL `~/embedded/embedded-sdk`
> 项目目录：WSL `~/rc_car/`
> 开发方式：Claude Code (WSL)

## 1. 开发流程（Claude Code 工作流）

```
Claude Code (WSL)                     你 (Windows)
─────────────────                     ────────────
写代码 → make 编译 → .bin 生成
     ↓
你说"编译好了，烧录试试"

     |  → 告诉我现象
     ↓
我分析日志 → 修改代码 → 重新编译
     ↓
  ...循环...
```

**你的任务**：烧录.bin、按复位、观察硬件现象、描述给我
**我的任务**：写代码、编译、分析日志、排查问题

## 2. 环境信息

### WSL 工具链
```
gcc-riscv64-unknown-elf  (等价于 riscv-none-embed-gcc)
binutils-riscv64-unknown-elf
picolibc-riscv64-unknown-elf
```

### SDK 路径
```
~/embedded/embedded-sdk/     ← SDK 本体
~/rc_car/                    ← 项目目录
```

环境变量 `ECOS_SDK_HOME` 已设到 `~/.bashrc`。

### 编译命令
```bash
cd ~/rc_car && make          # 编译
cd ~/rc_car && make clean    # 清理
```

编译产物：`~/rc_car/build/retrosoc_fw.bin`

### 串口
- CP2102 USB-to-UART → **COM5**
- 串口配置：**115200 8N1**（波特率115200，数据位8，无校验，停止位1）
- 终端工具：Tabby / Putty / MobaXterm 均可
- 操作：打开串口终端 → 配置参数 → 开发板按复位键 → 看输出日志

### 烧录步骤（你来做）
1. 开发板断电 → FLASH_SEL=MCU → 上电
2. 拖拽 `retrosoc_fw.bin` 到 HFP-LINK 虚拟U盘
3. 等 LED4 停闪 → 确认 Success
4. FLASH_SEL=CHIP → 按复位 → 看串口

## 4. 星空C1 关键寄存器

### SYS_UART (调试串口) @ 115200
```c
#define REG_UART_0_CLKDIV   (*(volatile uint32_t*)0x03000010)
#define REG_UART_0_DATA     (*(volatile uint32_t*)0x03000014)
// CLKDIV = 72000000/115200 - 1 = 624
```

### GPIO (电机方向控制)
```c
#define REG_GPIO_0_DR     (*(volatile uint32_t*)0x03000000)  // 数据
#define REG_GPIO_0_DDR    (*(volatile uint32_t*)0x03000004)  // 方向(1=输出)
// bit0=GPIO_0(AIN1), bit1=GPIO_1(AIN2), bit2=GPIO_2(BIN1), bit3=GPIO_3(BIN2)
```

### PWM (电机调速) @ 10kHz
```c
#define REG_PWM_0_CTRL    (*(volatile uint32_t*)0x03004000)
#define REG_PWM_0_PSCR    (*(volatile uint32_t*)0x03004004)  // 预分频
#define REG_PWM_0_CMP     (*(volatile uint32_t*)0x0300400c)  // 周期
#define REG_PWM_0_CR0     (*(volatile uint32_t*)0x03004010)  // 通道0 (左)
#define REG_PWM_0_CR1     (*(volatile uint32_t*)0x03004014)  // 通道1 (右)
```

### HP_UART (蓝牙通信) @ 115200
```c
#define REG_UART_1_LCR    (*(volatile uint32_t*)0x03003000)
#define REG_UART_1_DIV    (*(volatile uint32_t*)0x03003004)
#define REG_UART_1_TRX    (*(volatile uint32_t*)0x03003008)
#define REG_UART_1_LSR    (*(volatile uint32_t*)0x03003010)
```

## 5. 踩坑记录

1. **SDK hello 工程配的是 C2 不是 C1** → 第一次烧录没输出就是因为板型不对
2. **CP2102 驱动未装** → 设备管理器黄叹号，装驱动后出现 COM5
3. **需要手动实现 UART 驱动** → C1 没有现成的 sys_uart.c，需参考 board.h 寄存器
4. **freestanding 编译需加 include 路径** → picolibc + SDK libc
