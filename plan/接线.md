## 一、接线指南

免焊接搭建，全部用杜邦线+面包板。分5步接，每步接完检查一遍再下一步。

### 第0步：准备工作

先把所有模块摆在桌面上，确认你手头有：
- 星空C1开发板
- TB6612FNG电机驱动模块
- HC-05蓝牙模块（带底板）
- LM2596降压模块
- 2个TT电机（带轮子）+ 2个万向轮
- 7.4V锂电池（带保护板）
- 船型开关
- 面包板
- 杜邦线（公对公、公对母都要）
- 小一字螺丝刀（调LM2596电位器用）

### 第1步：调LM2596输出电压（不接任何其他东西）

```
电池(7.4V) ── 船型开关 ── LM2596 IN+/IN-
                              │
                         万用表接OUT+/OUT-
```

1. 电池正极接船型开关中间脚，开关另一脚接LM2596的IN+
2. 电池负极接LM2596的IN-
3. **先不接任何负载**，用万用表量LM2596的OUT+和OUT-
4. 用螺丝刀拧LM2596上的蓝色电位器，把输出调到 **5.0V**（4.9~5.1都行）
5. 调好后断开电池

> ⚠️ 这步必须先做！LM2596出厂默认输出可能不是5V，直接接开发板可能烧。

### 第2步：共地线（最重要的一步）

在面包板上把所有GND连在一起：

```
面包板GND轨 ←── 电池负极
            ←── LM2596 OUT-
            ←── 开发板 GND
            ←── TB6612 GND
            ←── HC-05 GND
```

> ⚠️ GND不共地是新手最常犯的错误，会导致信号乱码、电机乱转。

### 第3步：接电源线

| 从 | 到 | 说明 |
|----|----|------|
| 电池正极（经船型开关） | LM2596 IN+ | 电池7.4V输入 |
| LM2596 OUT+ (5V) | 开发板 5V/VIN | 给开发板供电 |
| LM2596 OUT+ (5V) | HC-05 VCC | **HC-05接5V，不接3.3V！** |
| LM2596 OUT+ (5V) | 面包板5V轨 | 备用 |
| 开发板 3.3V | 面包板3.3V轨 | 给TB6612逻辑供电 |
| 面包板3.3V轨 | TB6612 VCC | 逻辑电源3.3V |
| 面包板3.3V轨 | TB6612 STBY | 使能脚，**必须接，不接不工作** |

> 注意：TB6612有两个电源脚——VCC（逻辑，接3.3V）和VM（电机动力，接电池7.4V）。别搞反。

### 第4步：接电机驱动信号线

```
开发板                TB6612模块
─────────            ──────────
GPIO_0  ──────────→  AIN1    （左电机方向控制1）
GPIO_1  ──────────→  AIN2    （左电机方向控制2）
GPIO_2  ──────────→  BIN1    （右电机方向控制1）
GPIO_3  ──────────→  BIN2    （右电机方向控制2）
PWM_CH0 ──────────→  PWMA    （左电机调速）
PWM_CH1 ──────────→  PWMB    （右电机调速）
```

电机线（粗线，不走面包板，直接杜邦线接）：

```
TB6612                电机
──────                ────
AO1 ──────────────→  左电机 +
AO2 ──────────────→  左电机 -
BO1 ──────────────→  右电机 +
BO2 ──────────────→  右电机 -

TB6612 VM ─────────→ 电池正极（7.4V，经船型开关）
TB6612 GND ────────→ 电池负极（已在第2步共地）
```

> 接完后手动转一下轮子确认没短路。电机正负极接反不会烧，只是转向反了，后面软件调。

### 第5步：接蓝牙模块

```
开发板                HC-05模块
─────────            ──────────
CUST_UART_RX ←──────  TX      （HC-05的TX接开发板RX）
CUST_UART_TX ──────→ RX      （HC-05的RX接开发板TX）
5V          ──────→  VCC
GND         ──────→  GND
```

> ⚠️ TX和RX**交叉连接**，这是串口通信的基本规则。接反了不通信但不会烧。

### 接线总览图

```
                    ┌─────────────┐
   7.4V电池 ──开关──┤LM2596 降压   ├──5V──┬── 开发板VIN
                    └─────────────┘       ├── HC-05 VCC
                                          └── 面包板5V轨
   7.4V ────────────────────────────────── TB6612 VM（电机动力）
   
   GND全部连在一起（电池GND=LM2596 GND=开发板GND=TB6612 GND=HC-05 GND）

   开发板3.3V ──┬── TB6612 VCC（逻辑）
               └── TB6612 STBY（使能）

   开发板GPIO_0~3 ── TB6612 AIN1/AIN2/BIN1/BIN2
   开发板PWM_CH0~1 ── TB6612 PWMA/PWMB
   TB6612 AO1/AO2 ── 左电机
   TB6612 BO1/BO2 ── 右电机

   开发板CUST_UART_RX ←── HC-05 TX
   开发板CUST_UART_TX ── HC-05 RX
```

### 接完后的检查清单

逐项确认，全部打勾再上电：

- [ ] LM2596输出调到了5V
- [ ] 所有GND连在一起（万用表蜂鸣档挨个量）
- [ ] HC-05的VCC接的是5V，不是3.3V
- [ ] TB6612的STBY脚接了3.3V
- [ ] TB6612的VM接的是电池7.4V，VCC接的是3.3V
- [ ] HC-05的TX/RX是交叉接的
- [ ] 电机线没短路（万用表量AO1-AO2不通，BO1-BO2不通）
- [ ] 船型开关在断开位置

全部确认后，打开船型开关，观察：
- 开发板红色电源指示灯亮 ✅
- HC-05上的红灯快闪（约2次/秒）✅ 表示等待配对
- 没有冒烟、没有发烫 ✅

## 二、连完硬件就能让AI开发了吗？

**还不能，差两步：**

### 还差什么

| 步骤 | 做什么 | 为什么 |
|------|--------|--------|
| **1. 环境验证** | 在开发板上跑一个Hello World，确认SDK、编译器、烧录都通 | AI写的代码编不过/烧不进去，你分不清是代码问题还是环境问题 |
| **2. 串口调通** | 用串口终端看到开发板的printf输出 | 这是后面所有调试的基础，没有日志就是盲飞 |

这两步对应执行计划里的Phase 0。**Phase 0过了，才能让AI写驱动代码。**

### 具体操作

**1. 装环境（按ECOS-SDK文档来）**
```
git clone ECOS-SDK仓库
安装 riscv-none-embed-gcc 工具链
编译自带的Hello World示例
```

**2. 烧录Hello World**
```
开关拨到MCU模式 → 拖拽.bin到HFP-LINK → 等LED4停闪 → 开关拨回CHIP → 复位
```

**3. 打开串口终端**
```
Tabby/Putty → 选开发板的COM口 → 115200 8N1
复位开发板 → 看到串口输出 "Hello World" 就算通过
```

### Phase 0过了之后的开发流程

```
你 ──把prompt给AI──→ AI写代码
你 ──编译──→ 报错？→ 把报错贴给AI → AI改 → 重新编译
       ↓
     编译通过
       ↓
你 ──烧录到开发板──→ 串口看日志
       ↓
   现象对吗？
   ├── 对 → 进下一阶段
   └── 不对 → 把串口日志+现象描述贴给AI → AI分析改代码 → 重新烧录
```

**关键点**：AI不能直接碰你的开发板，所有编译、烧录、观察现象都是你来做。AI的角色是写代码+分析你反馈的问题。所以你要当好AI的"手和眼"。

### 总结

```
现在 ──→ 接线 ──→ 检查清单全打勾 ──→ 上电确认灯亮 ──→ Phase 0环境验证
                                                          ↓
                                                    Hello World串口能看到输出
                                                          ↓
                                                    ✅ 可以开始让AI写Phase 1代码了
```

接线先搞，搞完拍照我帮你检查，然后我们一起过Phase 0。
